# 合同风险审查

## 适用场景
用户提出以下类型请求时适用本技能：
- 审查某份合同的风险（"帮我看看合同 101 有没有风险"）
- 评估合同能否安全签署、是否需要补充材料
- 检查合同的用印、归档、OCR 完整性状态并给出综合判断

## 执行步骤

### 第一步：获取合同全量数据
调用 `getContractDetail`，参数从用户输入中提取：
- contractId: 合同 ID

若用户未指明合同 ID，先用自然语言向用户确认目标合同，不要凭空猜测。

### 第二步：执行风险审查
调用 `reviewContractRisks`，传入第一步获得的合同 ID。

### 第三步：综合研判并输出结论
基于两步工具返回的数据，输出结构化结论，必须包含：
- **风险等级**：low / medium / high
- **风险因素**：逐项列出（如用印待办、归档缺失、OCR 摘要缺失等），并说明每项的影响
- **处置建议**：明确下一步动作（可签署 / 补充用印 / 先归档再签署 / 需人工复核）

## 输出要求
- 风险等级必须有依据：逐项对应工具返回的具体状态字段，不得泛泛而谈
- 多项风险并存时，按影响程度从高到低排列
- 结论面向经办人，直接可执行，不暴露内部 ID 与关联字段
