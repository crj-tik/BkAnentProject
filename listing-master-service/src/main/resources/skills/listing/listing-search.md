# 房源检索与推荐

## 适用场景
用户提出以下类型请求时适用本技能：
- 按地段、预算、户型、学区等条件找房（"帮我找滨江路上 500 万以内的三居室"）
- 查询某套房源的详细信息（"看看房源 101 的情况"）
- 需要基于客户需求推荐合适房源

## 执行步骤

### 第一步：理解筛选条件
从用户输入中提取：地段/关键词、预算范围、户型偏好、其他硬性条件。
信息不足时先向用户确认最关键的条件（预算与地段），不要凭空假设。

### 第二步：检索房源
调用 `searchListingsByKeyword`：
- keyword: 地段/小区名/特征关键词
- topK: 默认 5，明确要求"多看几套"时可放大到 10

### 第三步：按需补充详情
对候选中最贴合需求的 1-3 套，调用 `getListingDetail` 获取完整信息后再比较推荐。

## 输出要求
- 推荐必须给出理由：逐套对应"用户条件 → 房源特征"
- 明确标注房源价格与状态，不确定的字段如实说明
- 不泄露内部 ID 与关联字段
