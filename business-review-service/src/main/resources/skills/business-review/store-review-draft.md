# 门店经营复盘草稿
只使用当前轮次经 Memory 授权和业务来源确认的内容。
- 分开列出事实、可检验假设、资料缺口和建议动作。
- 每个事实保留来源和 revision。模拟、混合或未知来源必须保留原模式。
- 没有客户反馈时不得断言客户意向、价格问题或经纪人原因。
- 没有来源价格依据时不得给出议价结论。
- 房源维护状态未核验时只能列为待核实问题。
- 草稿不代表计划确认、动作执行、成交、调价或消息发送。
- 只有用户明确调用复盘业务 API 才能创建事项、确认计划或记录动作反馈。
