# 后端能力清单（前端设计初稿）

本清单按当前代码和网关路由整理，为页面设计提供功能范围。详细接口字段、错误码、权限和运行状态尚未在全域完成核对，不能视为完整联调契约；接口源码盘点见 [后端接口盘点](backend-api-inventory-draft.md)。

当前仓库 Nacos 网关模板已为 10 条活动路由配置精确受众，并与 Auth `gateway-current` ACL 对齐。目标环境是否已发布此模板、是否存在运行配置覆盖，以及各路由能否完成目标服务验收仍待确认，见 [KI-236](known-issues.md)；受众映射通过不代表下游业务授权已通过。

| 页面或功能组 | 后端已出现的能力 | 设计关注点 |
| --- | --- | --- |
| 登录与权限管理 | 登录、令牌刷新和登出；用户角色、权限目录、业务管理员、经纪人和门店身份管理 | 角色授权与业务身份分别维护；详见 [Auth 契约](contracts/auth-frontend-current.md) |
| 房源 | 新增、编辑、删除、详情、搜索、状态、素材、OCR、核验；房源比较与报告/PDF | 列表筛选、详情、操作结果和报告状态；比较能力已归入房源服务 |
| 客户 | 客户资料、跟进记录、匹配房源、委托和到期提醒、收藏房源 | 客户归属权限、列表筛选及异步提醒结果 |
| 平台经营 | 经营分析、门店复盘、计划及反馈、知识案例审核发布与撤回 | 参照 [平台经营功能清单](platform-operations-frontend-function-list.md) 和 [OpenAPI](contracts/platform-operations-v1.openapi.yaml)；门店范围来自可信身份 |
| 营销内容 | 营销计划准备、内容审核、确认、投放回执、效果同步、ROI 和品牌素材 | 区分内容审核、执行回执和效果统计，不将模拟结果作为真实投放效果 |
| 通知 | 通知列表、已读、未读数、工作流事件；站内信、邮件和机器人发送入口 | 普通用户操作与发送管理入口的权限需分别核对 |
| 访谈 | 会话及邀请、问题准备与确认、开始、流式轮次、报告任务、资产发布和撤回 | 区分主持人、参与人和票据；处理流式断线与报告异步状态 |
| 智能工作台 | Agent 对话、任务、工作流、审批、执行状态和事件流；Studio 工作项、消息、产物和版本 | 区分普通工作台与治理、审计和工具管理入口；处理异步、取消及失败状态 |
| 用户与系统管理 | 用户、角色、权限目录及身份关系；Agent 治理、审计和配置接口 | 管理界面以实际授权和配置开关为准 |

媒体任务、Memory、RAG、跨服务来源接口和健康检查也在后端中存在；是否直接开放给浏览器，须按实际网关路由、调用方和权限逐项确认。合同与结算业务域已退役。完整页面字段表、状态枚举、输入输出 schema、错误码、权限矩阵和示例仍需补齐。
