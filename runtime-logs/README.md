# 日志与会话输出约定

所有本地运行输出和排查日志统一放在本目录，不要写到仓库根目录，也不要提交运行日志。

## 会话日志

新建会话日志时使用以下目录结构：

`runtime-logs/sessions/YYYY-MM-DD/<session-id>/<任务或服务名>.<stdout|stderr>.log`

- 日期使用日志生成当天的本地日期。
- `<session-id>` 使用会话自身的稳定标识；若工具没有会话标识，使用简短且唯一的任务名。
- 标准输出与错误输出分别写入 `.stdout.log` 和 `.stderr.log`；只有单路输出时使用 `.log`。
- 同一会话的多个任务放在同一会话目录，并用任务或服务名区分。
- 不覆盖其他会话的日志；重跑时追加尝试编号或时间后缀。

## 微服务运行日志

已有的 `runtime-logs/<服务名>.log` 与 `runtime-logs/<服务名>.err.log` 是历史运行文件。新会话请存入上述会话目录，并按服务名区分文件。排查结束后保留有复用价值的日志；临时输出可从本地目录清理，但清理前应确认它不是正在使用的文件。

## 历史诊断归档

旧的根目录临时诊断文件按生成日期放入 `runtime-logs/diagnostics/YYYY-MM-DD/`，保留原文件名和内容。诊断归档只保存在本地，不进入 Git。
