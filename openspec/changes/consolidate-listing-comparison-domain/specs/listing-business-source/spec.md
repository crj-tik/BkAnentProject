# 房源经营来源契约

## Purpose

为通过接口进入系统的房源建立统一的来源身份、当前授权、版本与量纲契约，使同域检索、对比和维护建议能够引用可复核事实。明确模拟数据、上游事实与本地处理记录的含义，支持以后替换真实接口而不改变业务结果的可追溯性。

## ADDED Requirements

### Requirement: 房源接口返回稳定来源及数据性质

系统 SHALL 通过已配置来源接入房源，并返回来源系统、上游 ID、版本或规范内容 hash、观察时间及服务端确认的数据模式。来源身份 MUST 保持无歧义和稳定，模拟来源 MUST 标记 SIMULATED，无法确认性质的历史来源 MUST 标记 UNKNOWN；调用者不得自行将模式改为 REAL。

#### Scenario: 模拟接口返回房源
- **WHEN** 房源来自显式配置的模拟来源
- **THEN** 列表、详情和所有派生结果均保留 SIMULATED、稳定来源引用及版本，不能只返回无来源字段的真实房源外观

#### Scenario: 不同来源具有相同上游 ID
- **WHEN** 两个来源返回相同字符串 ID
- **THEN** 系统保留为不同来源身份，不因数值转换、截断或哈希碰撞合并为一套房源

### Requirement: 读取权来自当前可信身份和资源范围

房源详情、搜索、导出及下游引用 SHALL 在正文输出前核验当前用户、来源资源状态和有效范围；服务名、brokerId、房源 ID、来源 hash 和普通模型 metadata MUST NOT 授予权限。范围适配不可用或当前身份无效 MUST 拒绝读取。

#### Scenario: 已缓存房源的读取权撤回
- **WHEN** 调用者曾可读某套房源，但当前已无权访问
- **THEN** 系统拒绝输出其缓存正文、对比字段和诊断细节，不凭先前成功回执放行

### Requirement: 房源单位和未知字段显式表达

房源来源 SHALL 明确金额单位、币种、面积单位及关键事实的未知状态。系统 MUST 在公开量纲边界准确转换一次，缺失总价或有效面积时不得构造单价；无可靠来源的通勤、核验、学区等事实不得由模型补齐。

#### Scenario: 旧万元输入转换为元单价
- **WHEN** 来源总价为 320 万元且面积为 100 平方米
- **THEN** 元单价为 32000 元每平方米，来源总价单位仍可追溯，不能重复乘以 10000

#### Scenario: 缺少核验材料
- **WHEN** 上游未提供当前有效的核验依据
- **THEN** 系统表达未知或待核实，不因本地 OCR 样例值或字段非空就宣称真实核验通过

### Requirement: 上游事实与本地维护记录分别表达

外部来源的价格、挂牌状态和权属类事实 SHALL 由对应接口事实决定。本地维护任务和补充记录 MUST 明确自己的操作者、时间和证据级别；缺少上游写入回执时不得声称上游事实已经更新。

#### Scenario: 操作人提交已联系业主
- **WHEN** 操作人完成本地维护事项但没有上游价格变更回执
- **THEN** 系统保存处理记录，保持原上游价格及版本，不把待办完成当成调价成功

### Requirement: 来源变化和依赖故障保持真实语义

输出和使用房源派生材料前 SHALL 复核来源版本及状态。来源删除、撤权、改变或不可达 MUST 有可辨识结果；HTTP 来源故障不得静默切换模拟数据，RAG 故障不得重启另一套关键词/向量执行链。

#### Scenario: 真实接口读取失败
- **WHEN** 已选择的接口来源超时或不可用
- **THEN** 系统报告来源不可用，不用模拟房源或旧缓存宣称当前读取成功

#### Scenario: 来源更新影响索引与报告
- **WHEN** 同一来源房源的有效版本变化
- **THEN** 相关投影按版本更新，旧报告可识别为过时，来源最终复核不以索引尚未同步为由返回失效事实
