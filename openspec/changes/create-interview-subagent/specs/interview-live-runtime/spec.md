# interview-live-runtime（运行面）Delta

## Purpose

定义访谈运行面的会话生命周期行为：固定话轮管线与确定性决策、收尾双通道与持久锁、入模脱敏与出模质量门、空返回兜底、可靠落库、访后归集与 L0–L3 评级、案例卡报告持久化任务，以及运行面自包含约束。

## ADDED Requirements

### Requirement: 固定话轮管线与单次造句

每个受访者话轮 SHALL 经固定代码管线处理：输入预处理 → 信号识别 → 追问决策 → 记忆装配 → 恰好一次造句模型调用 → 出模质量门 → 落库与下发。追问、换角度、转题、收尾决策 MUST 由代码作出；模型仅按既定决策生成话术；每次话轮的模型调用 MUST 恰好一次（空返回兜底重试除外）。

#### Scenario: 深度上限触发转题

- **WHEN** 某题追问深度达到该题深度上限
- **THEN** 管线决定转题，模型输出为转题话术而非继续深挖

#### Scenario: 播出前拦截换皮重问

- **WHEN** 造句结果与近期已问问题经相似度判定构成换皮重问
- **THEN** 该输出被拦截，按管线规则替换为换角度或转题话术

### Requirement: 收尾双通道与持久锁

受访者明确道别 SHALL 无条件进入收尾；「我说完了/就这些」类软完结 SHALL 仅在全部确认题问完后收尾，否则推进下一题；会话一旦进入收尾，MUST 维护持久锁：后续任何输入仅获得极短对等道别，不再产生新问题。

#### Scenario: 硬道别即收尾

- **WHEN** 受访者发送明确道别（如「拜拜」「再见」「今天就这样」）
- **THEN** 会话进入收尾并致谢结束

#### Scenario: 软完结需题清

- **WHEN** 受访者表示「就这些」但仍有未问确认题
- **THEN** 不收尾，礼貌确认后推进下一题

#### Scenario: 收尾后不再追问

- **WHEN** 会话已收尾后受访者再次发言
- **THEN** 仅回复简短对等道别，不产生新问题

### Requirement: 入模脱敏与出模质量门

话轮内容进入模型前 SHALL 对姓名、手机号、价格、地址执行脱敏，脱敏映射表 MUST 仅存服务端、不进入任何模型上下文；模型输出下发给受访者前 MUST 通过质量门：违禁问句族拦截（反事实假设、策略提炼、逐字复述压力、诱导预设、角色越界、换人复制类）、相似度去重、违禁词剥离、长度硬截断。

#### Scenario: 模型不可见原始隐私

- **WHEN** 话轮内容包含手机号等敏感信息
- **THEN** 送入模型的内容不含原始敏感值，且访中任何模型调用均不携带映射表

#### Scenario: 违禁问句不播出

- **WHEN** 造句输出命中违禁问句族
- **THEN** 该输出被拦截并替换，受访者不会看到违禁内容

### Requirement: 空返回兜底

造句调用流式空返回时 SHALL 以非流式重试一次；仍为空 MUST 以题单下一题接住话轮，MUST NOT 向受访者发送空回复或无决策依据的泛化追问。

#### Scenario: 两级兜底

- **WHEN** 流式与非流式调用均返回空
- **THEN** 回复内容为题单下一题的题目原文

### Requirement: 会话状态机

会话 SHALL 按 DRAFT → QUESTIONS_CONFIRMED → IN_PROGRESS → CLOSING_LOCKED → COLLECT_PENDING → ARCHIVED 顺序推进；状态推进 MUST 由服务端判定，调用方与模型不可跳过状态；收尾后 MUST 等待全部话轮落库完成方可进入归集。

#### Scenario: 未确认题不得开讲

- **WHEN** 会话处于 DRAFT（题目未确认）时请求启动访谈
- **THEN** 请求被拒绝并提示先完成题目确认

#### Scenario: 收尾等待落库

- **WHEN** 会话触发收尾且仍有话轮未落库
- **THEN** 会话在全部话轮确认落库后才进入 COLLECT_PENDING

### Requirement: 访后归集与 L0–L3 评级

会话归集 SHALL 生成逐字稿资产，并按确定性规则评级（正文长度、对象明确、主题聚焦、模块闭环、证据充分、话轮数六项检查）：L0 拒收、L1 待补充、L2 正式归档、L3 标杆归档；评级 MUST 不调用模型；元数据缺失 MUST 强制降级；补齐元数据后 MUST 支持按同一规则重评级；归集任务 MUST 具备失败补偿（重试上限与退避）。

#### Scenario: 规则评级

- **WHEN** 归集完成
- **THEN** 资产获得 L0–L3 等级与逐项评级依据，全过程无模型调用

#### Scenario: 补齐元数据重评

- **WHEN** L1 资产补齐缺失元数据并请求重评级
- **THEN** 按同一规则重新评级并更新等级与依据

### Requirement: 案例卡报告持久化任务

案例卡报告生成 SHALL 以持久化任务执行（租约、错误分级重试、进程重启可续跑）；同会话的并发报告请求 MUST 复用同一任务；已成功的报告 MUST 幂等返回且不再调用模型；报告中的受访者原声引用 MUST 经服务端原声逐字核验，命不中的引用自动降级为「转述」并归入缺失三分类（访谈缺口 / 需外部核验 / 待后续研究）。

#### Scenario: 并发请求复用任务

- **WHEN** 同一会话的两个报告请求先后到达且任务未完成
- **THEN** 两个请求关联同一任务，模型调用不重复

#### Scenario: 幂等返回既有报告

- **WHEN** 会话已有成功报告且输入快照未变时再次请求
- **THEN** 直接返回既有报告，不产生新的模型调用

#### Scenario: 原声核验降级

- **WHEN** 报告草稿中的原声引用无法在逐字稿中逐字命中
- **THEN** 该引用标记为「转述」，并计入对应的缺失三分类

### Requirement: 运行面自包含与 SLO

访中管线在会话进行中 SHALL 不产生对其他业务服务的同步调用（知识检索为开台时预读并缓存于会话）；单轮话轮处理延迟 MUST ≤6 秒，开台出题 MUST ≤25 秒。

#### Scenario: 访中零跨服务调用

- **WHEN** 会话进行中处理任一话轮
- **THEN** 管线内不发生对其他业务服务的同步请求

#### Scenario: 单轮延迟达标

- **WHEN** 正常话轮处理完成
- **THEN** 从收到输入到回复下发的总延迟不超过 6 秒
